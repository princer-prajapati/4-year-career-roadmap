# IT Career Roadmap | 4-Year Technical Career Planner

A responsive, bilingual web application that transforms broad career ambitions into a realistic, trackable, 16-quarter roadmap for students and early-career professionals preparing for high-impact IT roles.

---

## Key Features

1. **Bilingual Interface (English & Simple Hinglish)**:
   - Default Hinglish guidance for conversational, non-intimidating explanations.
   - One-click toggle between English and Hinglish in the top bar.

2. **Personalized 4-Year Roadmap (16 Quarters)**:
   - Full 16-quarter curricula for 6 distinct tech tracks:
     - Software Engineering (Full Stack & Backend)
     - Data Science & Analytics
     - AI & Machine Learning Engineering
     - Cloud Computing & DevOps / SRE
     - Cybersecurity & InfoSec
     - Product Management & Tech UX
     - Universal Track Finder for undecided learners
   - Workload auto-calibrated to user's weekly study hours (6 to 35+ hrs/week).

3. **Honest Reality Check**:
   - Zero false guarantees or misleading "get-rich-quick" packages.
   - Explains that real outcomes depend on problem-solving consistency, project depth, geography, market timing, and effort.

4. **Complete Views & Portability**:
   - **Dashboard**: High-level progress, current quarter focus, this week's action list, and an interactive 4-year progression matrix.
   - **16 Quarters Plan**: Deep dive into any quarter with skills checklist, practice drills, deliverables, career networking actions, milestones, and personal study notes.
   - **Project Tracker**: Manage live demo URLs and GitHub repository links for all 4 years.
   - **Skills Catalog**: Master searchable checklist of competencies.
   - **Job Readiness Audit**: 6-pillar rubric evaluating DSA, Portfolio, ATS Resume, System Design, STAR Stories, and Referrals.
   - **Track Comparison**: Side-by-side analysis of math intensity, coding intensity, and hiring market.
   - **Resources Hub**: Curated free books, official documentation, and interactive practice platforms.
   - **Profile & Settings**: Local storage persistence, JSON backup export, and backup restore.
